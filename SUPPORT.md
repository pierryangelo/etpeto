# Suporte

Use GitHub Discussions para perguntas, ideias e ajuda de configuração quando esse recurso estiver habilitado. Use issues para bugs reproduzíveis e tarefas aceitas.

Antes de abrir um relato, execute `make check`, consulte o [runbook](docs/runbooks/development.md) e procure ocorrências existentes. Informe sistema operacional, arquitetura, versões de Go/Bun/Docker, comando executado, resultado esperado e erro sanitizado.

Não publique credenciais, tokens, dados pessoais nem conteúdo de documentos administrativos reais. Vulnerabilidades seguem exclusivamente o canal privado descrito em [SECURITY.md](SECURITY.md).

O projeto é mantido por voluntários e não oferece SLA. Organizações que implantarem Etpeto devem operar seus próprios backups, observabilidade, atualizações e resposta a incidentes.
