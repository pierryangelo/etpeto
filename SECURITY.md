# Política de segurança

## Versões suportadas

Etpeto ainda está em fase pré-`v0.1`; não existe uma versão indicada para produção nem uma janela formal de suporte. Correções de segurança são aplicadas à branch `main`.

## Relatar uma vulnerabilidade

Não abra issue, discussão ou pull request público com detalhes exploráveis. Use o **private vulnerability reporting** do GitHub na aba **Security → Advisories → Report a vulnerability** deste repositório.

Inclua impacto, pré-condições, passos mínimos de reprodução e, se possível, uma sugestão de correção. Não inclua dados pessoais ou documentos reais. O mantenedor buscará confirmar o recebimento em até cinco dias úteis e coordenará correção e divulgação responsável.

Falhas de disponibilidade sem implicação de segurança e dúvidas de uso seguem o [guia de suporte](SUPPORT.md).
